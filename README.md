# Змейка 🐍

Классическая игра «Змейка», написанная на чистом HTML, CSS и нативном JavaScript без использования фреймворков и сторонних библиотек.

## 🎮 Возможности
- Плавное управление стрелками на клавиатуре
- Управление кнопками с пк и телефона
- Красивое шахматное поле с диагональной текстурой
- Змейка с раздельными скруглёнными сегментами, градиентом и глазами смотрящими по направлению движения
- Яблоко с объёмным градиентом, бликом и листиком
- Счётчик очков и сохранение абсолютного рекорда в памяти браузера
- Стартовое меню и экран поражения с эффектом размытия
- Запрет разворота на 180°

## 🚀 Как запустить
Достаточно открыть файл `index.html` в любом современном браузере, либо запустить проект через Live Server в VS Code.

## ⌨️ Управление
- Стрелки ← ↑ → ↓ для смены направления движения
- Кнопки на экране для смены направления движения
- Enter или клик по кнопке «Старт» для начала игры
